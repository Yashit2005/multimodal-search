Under the Hood

How It Works

CLIP (Contrastive Language–Image Pretraining) maps images and text into a shared 512-dimensional space via contrastive training on 400M pairs.

🖼
Image Encoder
Vision Transformer (ViT-B/32) processes images as 32×32 patches, producing a 512-d embedding normalized to unit length.
ViT-B/32 • 512-d
📝
Text Encoder
Transformer-based text encoder converts natural language queries into the same 512-d space. Matching image-text pairs land near each other.
Transformer • 512-d
⚡
FAISS Index
Flat inner-product index on L2-normalized vectors equals exact cosine search. C++ SIMD backend handles 100K+ vectors in <5ms.
IndexFlatIP • <5ms
🔀
Hybrid Search
Blend text and image embeddings: combined = α×text + (1-α)×image. Enables "find images like this, but with sunset lighting."
α-blend • tunable
🏷
Zero-Shot Classification
Embed each label as "a photo of a {label}", embed the image, take argmax of cosine similarities. No training data required.
No labels needed
🧠
Contrastive Training
In a batch of N pairs, CLIP pulls matching (image, text) pairs together and pushes N²–N mismatches apart, learning a joint embedding space.
400M pairs • OpenAI
